# מודל הניקוד – ליגת הפוצ'יוולי בחסות XIMOBILITY

> המסמך הזה מסכם איך צוברים נקודות במשחק הניחושים. אפשר לשתף אותו עם המשתתפים.
> הערכים כאן הם ברירת המחדל. המספרים המעודכנים תמיד מופיעים באתר, בעמוד **חוקי הניקוד**: https://ximobilityfantasy.vercel.app/rules

יש שלוש דרכים לצבור נקודות, וכולן מתחברות לדירוג הכללי. שלושת המקומות הראשונים בסוף העונה זוכים בפרסים מבית **XIMOBILITY**.

---

## 1. ניחוש תוצאות

בכל מחזור בעונה הסדירה מנחשים את התוצאה המדויקת של כל משחק, עד מועד הנעילה של המחזור.

| מה ניחשתם | נקודות |
|---|---|
| תוצאה מדויקת | **5** |
| רק המנצחת | **2** |
| לא נכון / לא ניחשתם | 0 |

**תוצאה חוקית:** מערכה אחת עד 21, ניצחון בהפרש 2 (למשל 21:15, 23:21). התקרה היא 25, כלומר 25:23 או 25:24.

---

## 2. ניחוש הטבלה

לפני תחילת העונה מסדרים את 12 הקבוצות לפי המיקום שלדעתכם יהיה להן בסוף העונה הסדירה.

| מה ניחשתם | נקודות |
|---|---|
| כל קבוצה במיקום הנכון | **3** (עד 36) |

מה המיקומים אומרים: 1–2 עולות לפיינל פור · 3–6 משחקות על שני מקומות נוספים (3 מול 6, 4 מול 5) · 9–10 בהצלבות מול הליגה השנייה · 11–12 יורדות ליגה.

---

## 3. רביעיית המחזור

בכל מחזור בוחרים **4 שחקנים** ו**קפטן** אחד מתוכם, עד מועד הנעילה.

| מי | נקודות לרביעייה שלכם |
|---|---|
| שחקן ברביעייה | הניקוד האישי שלו במחזור **× 2** |
| הקפטן | הניקוד האישי שלו במחזור **× 4** |

⚠️ **גם ניקוד שלילי מוכפל.** קפטן שקיבל כרטיס אדום יוריד לכם נקודות כפולות, אז בחרו בזהירות. (מנהל הליגה יכול לשנות את זה, כך שמינוס ייספר פעם אחת בלבד.)

---

## 4. הניקוד האישי של שחקן

מנהל הליגה מזין אחרי כל משחק את הנתונים של כל שחקן ששיחק. ניקוד המחזור של שחקן = הסכום מכל המשחקים שלו במחזור + בונוס מצטיין המחזור.

### נקודות שמתווספות
| פעולה | נקודות | איך נקבע |
|---|---|---|
| השתתפות במשחק | **+1** | כל שחקן שעלה לשחק |
| ניצחון | **+3** | אוטומטי לפי התוצאה |
| ניצחון מוחץ | **+2** | הפרש של 7 נקודות ומעלה, **בנוסף** לניצחון |
| המשחק הגיע להארכה | **+1** | התוצאה עברה את 21 (הגיעה ל-20:20). לכל מי ששיחק, גם למפסידים |
| חסימה | **+1** | לכל חסימה |
| פעולת הגנה מדהימה | **+2** | לכל פעולה |
| 8 נקודות אישיות ומעלה במערכה | **+2** | |
| 14 נקודות אישיות ומעלה במערכה | **+4** | **במקום** הבונוס של 8+ (לא מצטבר) |
| מצטיין המשחק | **+4** | שחקן אחד בכל משחק |
| מצטיין המחזור | **+5** | שחקן אחד בכל מחזור, **בנוסף** למצטיין המשחק |

### נקודות שיורדות
| פעולה | נקודות | הערה |
|---|---|---|
| כרטיס צהוב | **−2** | |
| כרטיס אדום | **−5** | צהוב ואדום לאותו שחקן **מצטברים** (−7) |
| טעות בלתי מחויבת | **−1** | לכל טעות |

### דוגמה
שחקן שניצח 21:13 (ניצחון מוחץ), עשה 2 חסימות ופעולת הגנה מדהימה אחת, קלע 14 נקודות ונבחר למצטיין המשחק, אבל טעה פעמיים:

| | |
|---|---|
| השתתפות | +1 |
| ניצחון | +3 |
| ניצחון מוחץ | +2 |
| 2 חסימות | +2 |
| הגנה מדהימה | +2 |
| 14+ נקודות | +4 |
| מצטיין המשחק | +4 |
| 2 טעויות | −2 |
| **סה"כ במשחק** | **16** |

אם הוא ברביעייה שלכם: **32** נקודות. אם הוא הקפטן: **64**.

## איפה רואים הכול באתר
- **חוקי הניקוד**: כל הערכים המעודכנים.
- **שחקנים**: הניקוד של כל שחקן, לכל העונה או לכל מחזור. עוזר לבחור רביעייה.
- **מחזורים**: אחרי הנעילה רואים את הנקודות שקיבלתם על כל משחק ועל כל שחקן ברביעייה.
- **דירוג**: הדירוג הכללי, עם פירוק לפי משחקים, טבלה ורביעייה.

*שינוי ערכי הניקוד ע"י מנהל הליגה מחשב מחדש את כל העונה.*
