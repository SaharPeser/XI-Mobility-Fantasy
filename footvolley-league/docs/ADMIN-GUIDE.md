# מדריך למנהל הליגה

נכנסים לאתר https://ximobilityfantasy.vercel.app עם המשתמש שלך, לוחצים על **כפתור התפריט** למעלה (שלושת הקווים) ובתחתית התפריט לוחצים **⚙️ ניהול**. בתוך אזור הניהול עוברים בין המסכים בשורה העליונה (עונה וניקוד, קבוצות ושחקנים, מחזורים ומשחקים, דירוג סופי).
כל השעות בעמודי הניהול הן לפי **שעון ישראל**.

## לפני תחילת העונה
1. **עונה וניקוד**
   - יוצרים עונה, למשל "ליגת XIMobility 2026". העונה הראשונה מסומנת כפעילה אוטומטית.
   - קובעים **נעילת ניחוש הטבלה**: המועד שאחריו אי אפשר לשנות את סדר הטבלה.
   - בודקים את ערכי הניקוד (ברירת מחדל: מנצחת 2, מדויקת 5, מיקום בטבלה 3, שחקן בשישייה ×2, קפטן ×4).
   - ממלאים את **פרסי XIMOBILITY** למקומות 1–3 ולוחצים **שמירה**.
2. **קבוצות ושחקנים**
   - מוסיפים את 12 הקבוצות.
   - **סמל קבוצה:** לוחצים על העיגול עם 📷 ליד שם הקבוצה, בוחרים תמונה, גוררים ומקטינים או מגדילים עד שהסמל בתוך העיגול, ולוחצים **שמירת סמל**. סמל רחב אפשר להקטין עד שהוא נכנס כולו, עם רקע לבן מסביב.
   - לוחצים על קבוצה ומוסיפים שחקנים, שם אחד בכל שורה, ובוחרים **לאום** (ישראלי או ברזילאי). הלאום חל על כל השמות שהוזנו באותה פעם, ואפשר לשנות אותו לכל שחקן בנפרד.
   - הלאום חשוב לשישיית המחזור: מותר לבחור בה לכל היותר 3 ברזילאים.
   - **תמונת שחקן:** לוחצים על העיגול עם 📷 ליד השחקן, בוחרים תמונה, גוררים אותה ומגדילים עם הזום כך שהפנים יהיו בתוך העיגול, ולוחצים **שמירת תמונה**. באותו חלון אפשר גם להחליף או להסיר תמונה. שחקן בלי תמונה יוצג עם ראשי התיבות שלו.
   - שחקן שעזב: מורידים את הסימון **פעיל** במקום למחוק. כך הניחושים הישנים עליו נשמרים.
3. **מחזורים ומשחקים**
   - **יצירת מחזורים** יוצר 11 מחזורים, אחד בכל שבוע, לפי מועד הנעילה של מחזור 1.
   - מתקנים את מועד הנעילה של כל מחזור לפי הצורך ולוחצים **שמירה**.
   - לוחצים **משחקים** ליד כל מחזור ומוסיפים את המשחקים: שתי קבוצות, מועד ומספר סדר.

## במהלך העונה, אחרי כל מחזור
1. **מחזורים ומשחקים → משחקים** של המחזור.
2. מזינים את **התוצאה** בכל משחק ולוחצים **שמירה**. התוצאה חייבת להיות חוקית: עד 21 בהפרש 2, מקסימום 25.
3. למטה, ב-**ניקוד אישי לשחקנים**, פותחים כל משחק:
   - מסמנים **שיחק** ליד כל שחקן שעלה לשחק.
   - ממלאים חסימות, הגנות מדהימות וטעויות בלתי מחויבות (מספרים).
   - בוחרים כמה נקודות אישיות הוא קלע: פחות מ-8, 8+ או 14+.
   - מסמנים **מצטיין** (אחד במשחק), וכרטיס **צהוב** או **אדום** אם היה.
   - לוחצים **שמירת נתוני המשחק**. ליד כל שחקן יופיע הניקוד שלו במשחק.
   - ניצחון, ניצחון מוחץ והארכה מחושבים לבד מהתוצאה, אז כדאי להזין קודם את התוצאה.
4. בוחרים **מצטיין המחזור** ולוחצים **שמירה**. הוא מקבל בונוס נוסף.
5. **תיקון ידני** (לא חובה): אם צריך לתקן ניקוד של שחקן, פותחים את "תיקון ידני" ומזינים מספר שיתווסף (או ירד, עם מינוס).
6. הדירוג ועמוד **שחקנים** מתעדכנים מיד.

את ערכי הניקוד האישי (כמה שווה כל פעולה), גודל השישייה ומכסת הברזילאים משנים ב-**עונה וניקוד → ניקוד אישי לשחקנים ושישיית המחזור**. את המודל המלא אפשר לשתף עם המשתתפים מתוך `SCORING-MODEL.md`, או לשלוח להם קישור לעמוד **חוקי הניקוד** באתר.

## בסוף העונה הסדירה
1. **דירוג סופי** → **מילוי לפי הטבלה המחושבת**, ואם צריך מתקנים ידנית (שוברי שוויון).
2. **שמירת דירוג סופי**. מעכשיו מחושבות הנקודות על ניחוש הטבלה.

## חשוב לדעת
- **מחיקה היא סופית.** מחיקת קבוצה, מחזור או משחק מוחקת גם את כל הניחושים עליהם. לכן יש חלון אישור לפני כל מחיקה.
- **שינוי ניקוד** בעונה מחשב מחדש את כל הדירוג, גם אחורה.
- **משתמש שכח סיסמה:** עדיין אין באתר מסך "שכחתי סיסמה". זה ברשימת התוספות ב-`ROADMAP.md`, ואפשר לבקש מ-Claude להוסיף.
- **למחוק משתמש:** ב-Supabase, **Authentication → Users**, מחפשים לפי מייל, **⋯ → Delete user**. כל הניחושים שלו נמחקים, וגם **ליגות חברים שהוא יצר נמחקות לכל החברים בהן**. המחיקה סופית.
- **מחיקת קבוצה או שחקן** מוחקת גם את התמונות והסמלים שלהם מהאחסון.
- **להוסיף מנהל נוסף:** מריצים ב-SQL Editor:
  ```sql
  update public.profiles set is_admin = true
  where id = (select id from auth.users where email = 'המייל@gmail.com');
  ```
