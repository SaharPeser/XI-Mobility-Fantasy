# 🏐 ליגת הפוצ'יוולי – משחק הניחושים

משחק ניחושים לליגת הפוצ'יוולי (בסגנון "5 חברה" / ליגת החלומות).
Next.js 16 + Supabase, פריסה ב-Vercel.

## מה יש במשחק

| חלק | איך זה עובד |
|---|---|
| **ניחוש תוצאות** | בכל מחזור בעונה הסדירה מנחשים תוצאה מדויקת (מערכה אחת עד 21, הפרש 2, מקסימום 25). ניחוש המנצחת = 2 נק', תוצאה מדויקת = 5 נק'. |
| **ניחוש טבלה** | לפני תחילת העונה מסדרים את 12 הקבוצות. בסוף העונה הסדירה: 3 נק' לכל קבוצה במיקום הנכון. |
| **רביעיית המחזור** | בוחרים 4 שחקנים וקפטן. השחקן מקבל פי 2 מהניקוד שהמנהל הזין לו במחזור, והקפטן פי 4. |
| **ליגות חברים** | כל משתמש יכול ליצור ליגה פרטית ולשתף קוד/קישור הזמנה. |
| **דירוג כללי** | כל המשתתפים, כולל הדגשה של 3 המקומות הראשונים (פרסים). |
| **עמוד ניהול** (`/admin`) | עונה והגדרות ניקוד, קבוצות ושחקנים, מחזורים ומועדי נעילה, משחקים ושעות, תוצאות, ניקוד שחקנים, דירוג סופי. |

כל ערכי הניקוד ניתנים לשינוי בעמוד הניהול, והדירוג מחושב מחדש אוטומטית.
הניחושים ננעלים במועד שהמנהל קובע לכל מחזור. אחרי הנעילה אפשר לראות גם את הניחושים של אחרים.

אזורי הטבלה: 1–2 פיינל פור · 3–6 פלייאוף (3 מול 6, 4 מול 5) · 9–10 הצלבות מול ליגה שנייה · 11–12 ירידה.

## הקמה – צעד אחר צעד

### 1. Supabase
1. פותחים פרויקט חדש ב-[supabase.com](https://supabase.com).
2. **SQL Editor** → מדביקים את כל התוכן של `supabase/migrations/20260924000000_init.sql` → Run.
   (או עם ה-CLI: `npx supabase link` ואז `npx supabase db push`)
3. **Authentication → URL Configuration**:
   - Site URL: כתובת האתר ב-Vercel (למשל `https://footvolley.vercel.app`)
   - Redirect URLs: להוסיף `https://footvolley.vercel.app/**` וגם `http://localhost:3000/**`
4. (לא חובה) **Authentication → Providers → Email**: אם רוצים הרשמה בלי אימות מייל, מכבים את "Confirm email".

### 2. הרצה מקומית
```bash
cp .env.example .env.local   # וממלאים את הערכים מ-Supabase → Project Settings → API
npm install
npm run dev
```

### 3. הגדרת המנהל
נרשמים באתר עם המייל שלכם, ואז ב-SQL Editor של Supabase:
```sql
update public.profiles set is_admin = true
where id = (select id from auth.users where email = 'YOUR@EMAIL.com');
```
מתנתקים ומתחברים מחדש, ויופיע כפתור "ניהול".

### 4. פריסה ב-Vercel
1. מעלים את הפרויקט ל-GitHub.
2. ב-Vercel: **Add New → Project** → בוחרים את ה-repo.
3. **Environment Variables**:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` (או ה-anon key)
   - `NEXT_PUBLIC_SITE_URL` = כתובת האתר ב-Vercel
4. Deploy.

## סדר עבודה למנהל בתחילת עונה
1. **עונה וניקוד** – יוצרים עונה, קובעים מועד נעילה לניחוש הטבלה, ובודקים את ערכי הניקוד.
2. **קבוצות ושחקנים** – מוסיפים 12 קבוצות, ולכל קבוצה את השחקנים (שם בכל שורה).
3. **מחזורים ומשחקים** – "יצירת מחזורים" יוצר 11 מחזורים (אחד בשבוע). אחר כך מתקנים מועדי נעילה לפי הצורך, ונכנסים לכל מחזור כדי להוסיף משחקים, שעות וסדר.
4. **אחרי כל מחזור** – מזינים תוצאות וניקוד לשחקנים (לרביעייה).
5. **בסוף העונה הסדירה** – "דירוג סופי" (אפשר למלא אוטומטית לפי הטבלה המחושבת ולתקן ידנית).

השעות בעמוד הניהול הן לפי שעון ישראל.

## מבנה הקוד
```
supabase/migrations/   סכמת המסד, הרשאות (RLS), חישוב הדירוג
supabase/tests/        בדיקות למסד (npm run test:db)
src/lib/scoring.ts     חוקי תוצאה, חישוב טבלה, אזורי הטבלה
src/app/rounds/        ניחושי מחזור + רביעייה
src/app/predict-table/ ניחוש הטבלה
src/app/leagues/       ליגות חברים
src/app/admin/         עמוד הניהול
```

**אבטחה:** כל ההרשאות נאכפות במסד הנתונים (Row Level Security): משתמש לא יכול לשנות ניחוש אחרי הנעילה, לראות ניחושים של אחרים לפני הנעילה, או לשנות נתונים של הליגה אם הוא לא מנהל.

## הרחבות עתידיות
- **ניקוד נוסף**: מוסיפים עמודה לטבלת `seasons` וחלק חדש בפונקציה `get_leaderboard`.
- **פלייאוף / פיינל פור / הצלבות**: כבר אפשר ליצור מחזורים עם שלב (`stage`) שונה. חוקי הניחוש המיוחדים להם יתווספו בהמשך.
